## Docker context gotcha (CRITICAL, check first)

Host has Docker Desktop (QEMU VM at `/home/kai/.docker/desktop/`) AND native dockerd. The `docker` CLI defaults to the `desktop-linux` context which routes to the VM. No GPU passthrough.

**Fix before any GPU docker work:**

```bash
docker context use default
```

Verify:

```bash
docker info | grep -iE "runtime|cdi"
# Should show `nvidia` in Runtimes and `nvidia.com/gpu` CDI devices.
```

Switch back when done:

```bash
docker context use desktop-linux
```

**Why this matters:** two hours wasted debugging "CDI unresolvable" errors that were actually the wrong daemon socket. Native dockerd has the nvidia runtime, CDI spec, and GPU access. The Desktop VM has none.

## apparmor gotcha (Ubuntu 24.04)

`kernel.apparmor_restrict_unprivileged_userns` must be `0` for CUDA to init from a venv Python. User's setting. They flip it manually per session. NOT persisted (their call for security).

supergraph's preload detects this and raises a targeted error. If you see CUDA init failures from a venv, suggest:

```bash
sudo sysctl -w kernel.apparmor_restrict_unprivileged_userns=0
```

## Resource limits (Rule 12)

All Docker commands on this host must cap at 8 CPUs and 16 GB RAM to prevent freezes. For `docker buildx`, cap the builder instance itself at 12 CPUs and 16 GB RAM on creation - the `--cpus` / `--memory` flags on `buildx build` are ignored.

```bash
docker buildx create --name gs-gpu --driver docker-container \
  --driver-opt "memory=16g" --driver-opt "cpuset-cpus=0-11" \
  --bootstrap
```

### Harrier GPU, 20 per category (paused mid-session)

To resume:

```bash

docker build -f benchmarks/framework/Dockerfile.bench.gpu -t supergraph-bench:gpu .

docker run --rm --gpus all --cpus=8 --memory=16g \
  -v /mnt/storage/harrier-gpu-export:/models/harrier-gpu \
  -v /home/kai/longmemeval-data:/data \
  supergraph-bench:gpu \
  python -m benchmarks.framework.docker_runner \
    --embedder onnx \
    --embedder-model-dir /models/harrier-gpu \
    --embedder-pooling last_token \
    --embedder-max-length 2048 \
    --embedder-output-dims 1024 \
    --gpu \
    --per-category 20 \
    --data /data/longmemeval_s_cleaned.json
```
